### prefix AUTH : Authentication / Authorization error

```
AUTH001 : Invalid or expired Token Provided
AUTH002 : No or Wrong Token Header Provided
AUTH003 : Insufficient Authorization Level
```

### prefix USER : User signup / signin error

```
USER001 : Requested E-mail is already on database
USER002 : Password rule violation.
USER003 : Requested E-mail not found in database
```

### prefix LGIN : User Login error
```
LGIN001 : Wrong password or user not found.
LGIN002 : User already logged in from another session.
```
